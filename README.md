📌 AniScreen – Anime Ticket Booking System
AniScreen is a real-time ticket booking platform tailored for anime movie lovers. Users can explore upcoming anime screenings, book tickets, and manage their reservations with ease. The platform features role-based access control for admins and users, secure payment integration, and a clean, responsive UI.

🔧 Tech Stack:
Frontend: React, Redux, Ant Design

Backend: Node.js, Express.js

Database: MongoDB (Mongoose)

Authentication: JWT-based login with role access (Admin/User)

Payments: Stripe API

State Management: Redux

💡 Key Features:
🔐 JWT Authentication with role-based login (admin/user)

🎬 Admin Dashboard to manage movies, theaters, and shows

🎟️ User Booking System for anime shows with real-time confirmation

💳 Stripe Integration for secure payments

📱 Responsive UI with Ant Design and Redux for smooth UX
